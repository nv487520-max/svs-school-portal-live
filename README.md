# SVS Public School Portal - Live App

🎓 **A complete school management portal with real-time issue tracking**

## 🚀 Live App Link
**👉 https://nv487520-max.github.io/svs-school-portal-live/**

Open this link in your browser to access the live app!

## 📋 Features

### Staff/Teachers Login
- **Roles**: Director, Principal, Teacher, Clerk
- **Demo Password**: `director123` / `teacher123` / `clerk123`
- Access to Attendance, Homework, Results, Quizzes, Staff Directory

### Parent Login
- **Demo Mobile**: `9897011111`
- View children's attendance, homework, results, fee status

### NEW: School Issue Form (Parents can report issues)
- Student name, parent name, phone number
- Issue type (Academic, Fee, Transport, etc.)
- Issue details and urgency level
- Live list of submitted issues
- Data saves automatically in browser

### Sections
- 📊 Dashboard - Quick stats
- 📝 Attendance - Mark & track
- 📚 Homework - Defaulter tracking
- 🏆 Results - Exam marks
- ⚠️ School Issue - Parent complaints & feedback
- 🎯 Quiz - Online tests
- 👨‍🏫 Staff Directory - Teachers contact info
